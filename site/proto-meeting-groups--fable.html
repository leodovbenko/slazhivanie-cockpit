Мои задачи — по группам встреч

Встречи из Контур.Толк рождают поручения. Сейчас они падают одной кучей. Идея: задача наследует группу своей встречи — регулярки раскладываются по направлениям, разовые по роли.

1Встреча несёт series_key

Стабильный код комнаты из Контур.Толк, например pntr.ktalk.ru/babis1uyva1x. Все прошедшие и будущие созвоны одной регулярки склеиваются по нему в одну серию.

2Направление = департамент из оргструктуры

Регулярка приписывается к направлению по департаменту участников в оргструктуре (СБИС/Saby). Не по цвету календаря: цвет — ручная метка автора, к нам он не приходит. Мы выводим то же деление формально.

3Ситуативные — по роли зрителя

Не-регулярные встречи группируются проще: я организатор / меня позвали / клиентская (есть внешний участник). Роль своя у каждого зрителя.

4Задача наследует группу, срез — по оргструктуре

Поручение получает группу встречи, из которой родилось. Группы живут на уровне компании, а срез каждого руководителя фильтруется по его поддереву подчинения — «свои регулярки у каждого» получаются сами.

Прототип интерфейса. Данные вымышленные, для демонстрации механики.
