Ваш голос

Гермес пишет не «нейросетевым» языком, а вашим. Голос настраивается отдельно для каждого канала: для русского Телеграма — один тон, для английского LinkedIn — другой. Один человек может вести сразу несколько каналов, и у каждого своё лицо.

По прошлым постам

Гермес читает то, что вы уже публиковали, и подхватывает манеру.

По образцам

Даёте пару текстов, которые звучат «как вы» — он берёт их за эталон.

Своими словами

Просто описываете: «коротко, по делу, без пафоса, с примером из жизни».

Голос можно поправить в любой момент — кнопкой «собрать голос» в кабинете или командой боту. Там же задаёте, чего избегать (например, «без канцелярита и хэштегов») и какие площадки ведёте.

Как подключить — по шагам

Метки: делаете сами — прямо в кабинете, за пару минут. делаем мы — настраиваем на своей стороне.

1
Подключить бота в Телеграме делаете сами Заводите бота (получаете токен у @BotFather) и подключаете в кабинете. Хотите постить в канал — добавьте бота админом этого канала.
2
Подключить соцсети делаете сами Привязываете аккаунты — LinkedIn, Instagram, YouTube, Дзен. После этого публикация идёт по кнопке.
3
Собрать голос делаете сами Нажимаете «собрать голос» или говорите боту. По вашим постам, образцам или описанию словами. Отдельно для каждого канала.
4
Выбрать, откуда идеи делаете сами По умолчанию — из дел команды, ничего делать не нужно. Есть группа компаний — отмечаете галочками нужные.
5
Настроить площадки и частоту делаете сами Для каждого канала — язык, длину, стиль. И как часто присылать идеи (или не присылать вовсе — по вашему выбору).
6
Включить видео-ведущего делаем мы Для рилсов настраиваем лицо и голос ведущего вместе с вами — это пока делается через нашего оператора.
7
Добавить со-авторов делаем мы Если постить в канал должны несколько человек из команды — выдаём им доступ поимённо.
